# 用户手册 (User Manual)

## 1. 快速开始
欢迎使用“未来图书馆”小说阅读系统。本系统提供简洁高效的纯净阅读体验。

## 2. 功能操作指南

### 2.1 发现小说
- **浏览**: 在首页你可以看到当前系统推荐的热门小说。
- **搜索**: 使用顶部的搜索框，输入小说名称或关键词即可快速定位书籍。

### 2.2 查看书籍详情
- 点击感兴趣的小说卡片，进入详情页面。
- 你可以查看书籍的完整简介及更新章节数。
- 点击“开始阅读”将跳转到第一章，或在目录中点击特定章节进入。

### 2.3 沉浸阅读
- 阅读页采用了护眼的暖色纸质风格。
- 点击下方的“返回目录”可以随时回到书籍列表。

### 2.4 作者后台：导出章节文本
- 点击顶部导航的「作者后台」进入导出页面（路由 `/admin/export`）。
- **选择作品**：在下拉框中选择一本作品，下方会展示该作品的章节列表及每章的「已发布 / 草稿」状态。
- **选择导出范围**：
  - **已发布章节**（`mode=published`）：仅合并状态为「已发布」的章节；
  - **完整稿件（含草稿）**（`mode=full`）：包含草稿章节，草稿标题后会标注「【草稿】」。
- 点击「导出章节文本 (.txt)」后，浏览器会下载一个 UTF-8 编码的 `.txt` 文件，文件名为 `作品名_YYYY-MM-DD_已发布章节.txt`（完整稿件时后缀为 `_完整稿件.txt`）；文件内的章节严格按章节序号（orderNo）升序合并。
- **导出失败时的提示含义**：
  - 「章节数据损坏」：某章缺少标题/正文/序号、状态缺失或序号重复，导出会中止并提示具体原因。请先修复该章节后再导出（HTTP 422，错误码 `CHAPTER_DATA_CORRUPTED`）。
  - 「文件写入失败」：服务器在生成/写出文件时发生磁盘 IO 问题（如磁盘已满、临时目录无权限）。请稍后重试或联系管理员（HTTP 500，错误码 `EXPORT_FILE_WRITE_FAILED`）。

## 3. 常见问题 (FAQ)

**Q: 为什么系统是浅色的？**
A: 为了提供更好的可读性，系统近期升级到了全新的浅色主题。

**Q: 我可以在移动端使用吗？**
A: 是的，系统完全适配移动端浏览器，你可以通过手机进行阅读。

**Q: 数据会丢失吗？**
A: 当前版本为内存存储演示版，重启容器后台数据会重置回初始种子数据。
