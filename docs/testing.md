## 3. 接口测试 (API Testing)
使用 Swagger 进行接口验证：
- `GET /api/novels`: 返回 200，JSON 包含分页数据。
- `GET /api/novels/1`: 返回书籍详情及已发布章节数据。
- `GET /api/chapters/1`: 正确返回正文字符串。
- `GET /api/novels/1/export`: 返回 200 与 `.txt` 附件，`Content-Disposition` 携带中文文件名（RFC 5987）。
- `GET /api/novels/1/export?includeDrafts=true`: 返回含草稿章节的完整稿件。
- `GET /api/novels/999/export`: 返回 404，错误码 `NOT_FOUND`。
- `GET /api/novels/3/export`: 返回 422，错误码 `NO_EXPORTABLE_CHAPTERS`。

## 3.1 自动化测试
